✅ Practical Task: Build a Recruitment AI Agent (Full
Project)
📌 Objective:
Create a fully functional Recruitment AI Agent using FastAPI that allows HR professionals to
upload job descriptions and resumes, and then evaluates candidates based on relevance to the
job.
🛠️ Requirements:
1. FastAPI Backend
●​ Use FastAPI to develop the entire backend for this project.​
●​ Ensure all endpoints are clearly documented using Swagger (FastAPI docs).​
2. Job Description Input Module
The user should be able to input the Job Description in 3 ways:
1.​ Upload a file: Accept PDF or DOC/DOCX files and extract the text.​
2.​ Manual input: A textarea where the user can write/paste the JD.​
3.​ Generate JD: Accept the following inputs and generate a JD using an AI model:​
○​ Job Title​
○​ Years of Experience​
○​ Must-have Skills (comma-separated)​
○​ Company Name​
○​ Employment Type (Full-time, Part-time, etc.)​○​ Industry​
○​ Location​
3. Resume Upload and Candidate Matching
●​ User can upload up to 10 resumes (PDF or DOC/DOCX).​
●​ Extract text from the resumes.​
●​ Compare each resume to the JD and assign a matching score out of 100.​
●​ Display:​
○​ Score​
○​ Missing skills​
○​ Remarks (brief explanation like “Lacks experience in X”, “Strong in Y”)​
4. Frontend Output Requirements
You can use simple HTML with Jinja2, or optionally React or Streamlit for the frontend.
●​ List of all candidates with:​
○​ Resume filename​
○​ Score​
○​ Missing skills​
○​ Remarks​
●​ Highlight the best matched candidate visually.​
●​ Show:​○​ Personalized interview call email (auto-generated by AI)​
○​ Rejection email (for other candidates)​
5. AI/LLM Integration
●​ You can use OpenAI GPT, HuggingFace Transformers, spaCy, or any other model to:​
○​ Generate Job Descriptions​
○​ Match resume content to JD​
○​ Create personalized emails​
📌 Mandatory: Explain in README
●​ Which AI model(s) you chose and why (performance, cost, accuracy, etc.)​
●​ How you used the model(s) in different parts of the project.​
6. Requirements
●​ Provide a requirements.txt file with all dependencies.​
●​ The project should be runnable with uvicorn or a similar ASGI server.
7. README.md
The README should contain:
🔧 Setup Instructions​
●​ 🚀 How to run the project locally​
●​ 🔍 Description of the AI logic​
●​ 🧠 Explanation of model choices​
●​ 🧪 Example JD and Resume files to test with​
